Un agent, deux visages

L'application Claude

  • Onglet Code de l'application de bureau.
  • On clique, on choisit un dossier.
  • Les modifications s'affichent en couleur.

Le terminal

  • On tape claude dans un dossier.
  • Tout se fait au clavier.
  • Plus de commandes, et l'automatisation.
C'est le même agent. Il lit les mêmes fichiers : CLAUDE.md, le dossier .claude/ avec vos skills et vos réglages. Ce que vous installez pour l'un sert à l'autre.

L'installer

L'application

  • Télécharger l'installateur sur claude.ai/download.
  • Se connecter avec son compte Claude.
  • Cliquer sur l'onglet Code.

Rien d'autre à installer.

Le terminal

  • Coller une commande dans PowerShell.
  • Ouvrir un nouveau terminal, taper claude.
  • Se connecter dans le navigateur, une seule fois.
Dans les deux cas, il faut un abonnement payant : Pro, Max, Team ou Enterprise.

Ce que l'agent trouve dans le dossier

Cours-2nde/
├─ CLAUDE.md vos consignes, lues à chaque session
├─ .claude/
│  ├─ skills/ savoir-faire du projet
│  ├─ commands/ vos commandes /…
│  └─ settings.json permissions, hooks
└─ fiche-equations.tex
  • Les mêmes dossiers existent dans ~/.claude/ : ils valent alors pour tous vos projets.
  • /init écrit un premier CLAUDE.md à partir du contenu du dossier.
  • /memory ouvre les fichiers CLAUDE.md pour les modifier.
  • Dans l'application, l'environnement peut aussi être Cloud ou SSH (machine distante) : « Local » suffit pour commencer.

Les modes de permission

ApplicationTerminalCe que l'agent fait sans vous demander
ManuelManualIl lit. Il demande avant de modifier un fichier ou de lancer une commande.
Accepter les modificationsAccept editsIl modifie les fichiers du dossier. Il demande avant les autres commandes.
PlanPlanIl lit et explore, sans rien modifier, puis propose un plan.
AutoAutoPresque tout ; un contrôle en arrière-plan bloque les actions risquées.
Contourner les permissionsBypassTout. À réserver à une machine isolée (conteneur, VM).

Le terminal démarre désormais en Auto quand ce mode est disponible. La barre d'état affiche le mode actif.
Les modifications Détail 2 / 2

Revenir en arrière

Avant d'accepter

  • Refuser : rien n'est écrit.
  • Dans l'application, commenter une ligne de la vue détaillée : l'agent lit le commentaire et corrige.
  • Au terminal, la réponse « Non » permet de dire ce qu'il faut faire autrement.

Après coup

  • /rewind ramène la conversation et/ou le code à un point antérieur.
  • Au terminal, Échap deux fois, zone de saisie vide, ouvre le même menu.
  • Demander simplement : « annule ta dernière modification ».
Un dossier sous Git ou sauvegardé reste la meilleure assurance.

Reprendre une session Détail 1 / 1

Plusieurs sessions en parallèle

Application

  • + Nouvelle dans la barre latérale, ou Ctrl+N.
  • Ctrl+Tab passe d'une session à l'autre.
  • Alt + clic : deux sessions côte à côte.
  • Bouton Worktree : la session travaille sur une copie isolée du projet (dossier sous Git).

Terminal

  • Une session par fenêtre de terminal.
  • claude --worktree pour l'isolement.
  • /clear ouvre une conversation neuve ; /resume retrouve l'ancienne.
Sans worktree, deux sessions dans le même dossier modifient les mêmes fichiers.

Le contexte : sa mémoire de travail

Contexte

72 % utilisés : consignes, fichiers lus, échanges.

Quand la jauge se remplit, l'agent résume lui-même la conversation pour continuer.

Deux réflexes

  • Nouveau sujet : /clear, une conversation neuve.
  • Même sujet, longue séance : /compact, un résumé qui garde l'essentiel.
Où voir la jauge : carte Contexte dans l'application, /context dans les deux.

Le contexte Détail 1 / 1

/compact ou /clear ?

/compact/clear
EffetRemplace l'historique par un résumé.Repart d'une conversation vide.
QuandOn continue le même travail, mais la séance est longue.On change de tâche.
AstuceDire quoi garder : /compact garde les décisions sur le barèmeL'ancienne conversation reste accessible avec /resume.
  • Le CLAUDE.md est relu à chaque session : ce qui doit toujours valoir va là, pas dans la conversation.
  • Les signes d'un contexte saturé : l'agent oublie les consignes du début.
  • /context détaille ce qui occupe la place (fichiers, outils, mémoire).

Six commandes à connaître

/clear

Nouvelle conversation, contexte vide.

/compact

Résume la conversation pour libérer de la place.

/model

Change de modèle (plus rapide ou plus puissant).

/resume

Reprend une conversation précédente.

/plugin

Installe et gère des plugins (skills, agents…).

/help

Affiche l'aide et les commandes disponibles.

Taper / affiche la liste : commandes intégrées, mais aussi vos skills et vos commandes personnelles.
