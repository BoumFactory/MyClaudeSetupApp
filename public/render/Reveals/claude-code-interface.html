Deux interfaces, un même moteur

Claude Desktop

  • Interface graphique (GUI)
  • 3 onglets intégrés
  • Idéal pour débuter
  • Pas de configuration
  • Multi-plateforme

Claude Code CLI

  • Interface terminal
  • Commandes personnalisées
  • Automation avancée
  • Scripts et workflows
  • Intégration DevOps
Point clé : Mêmes modèles Claude (Opus 5.5, Sonnet 5.5…) dans les deux interfaces. Choisissez selon votre workflow, pas selon la performance.

Claude Desktop - Les 3 onglets

Chat

Conversation naturelle avec Claude. Partagez texte, code, images. L'interface standard.

Cowork (agent de bureau)

Claude mène seul une tâche en plusieurs étapes dans un dossier que vous lui confiez : trier des fichiers, rédiger un document à partir de notes, produire un tableau. Offre payante. Attention : les suppressions sont définitives, sauvegardez le dossier avant.

Code

Claude Code dans une fenêtre : accès direct aux fichiers d'un projet, écriture et exécution de code. Même moteur que Cowork et que la version terminal.

Conseil : Commencez par Chat pour explorer, puis explorez Code et Cowork selon vos besoins.

Claude Code CLI - Installation

Prérequis

  • Git (Git for Windows sur Windows)
  • Un abonnement Claude (Pro, Max, Team ou Enterprise) ou un compte API sur console.anthropic.com
  • Terminal : bash, zsh, PowerShell ou CMD

Installation native (recommandée)

macOS / Linux

curl -fsSL https://claude.ai/install.sh | bash

Windows (PowerShell)

irm https://claude.ai/install.ps1 | iex
Node.js n'est plus nécessaire. L'installeur natif est autonome, plus rapide, et se met à jour automatiquement. Autres voies : winget install Anthropic.ClaudeCode (Windows), brew install --cask claude-code (macOS).

Premier lancement

claude

La première exécution vous connecte à votre compte Anthropic via le navigateur.

Commandes de base

/help

Affiche la liste de toutes les commandes disponibles.

/compact

Résume la conversation pour réduire l'utilisation du contexte.

/clear

Efface l'historique et démarre une nouvelle conversation.

/exit

Quitte le programme proprement.

Utilisation : Tapez la commande dans la conversation (ex: /help) et appuyez sur Entrée.
À connaître aussi : /model change de modèle · Maj+Tab passe en mode plan (Claude propose avant d'agir) · Échap interrompt Claude · claude --continue reprend la dernière conversation, claude --resume en choisit une ancienne.

Commandes personnalisées

Créez vos propres workflows : un fichier .md dans .claude/commands/, ou un skill dans .claude/skills/<nom>/SKILL.md.

Exemples fournis dans le setup partagé

/createTex

Génère un fichier LaTeX structuré (article, présentation, etc.)

/createReveals

Crée une présentation reveal.js complète avec plan et slides.

Autocomplétion

Tapez / pour afficher le menu des commandes et skills disponibles, puis Tab pour compléter.

Créez les vôtres : le fichier .claude/commands/maCommande.md contient simplement le prompt ; il s'appelle ensuite avec /maCommande.

Le fichier CLAUDE.md

Fichier lu à chaque session : à la racine du projet (ce projet) ou dans ~/.claude/CLAUDE.md (tous vos projets). /init en crée un premier jet.

Sans CLAUDE.md

$ claude > Qu'est-ce que vous voulez faire ? > Je dois créer un fichier LaTeX... > [Vous répétez chaque fois le contexte]

Avec CLAUDE.md

# Mon Workflow IA Tu es expert en création de documents LaTeX et présentations reveal.js. Commandes disponibles : - /createTex : Génère article LaTeX - /createReveals : Crée présentation reveal.js

Résultat : Claude comprend immédiatement votre contexte et applique vos consignes sans que vous ayez à les répéter.

Travailler avec des fichiers

Les trois opérations principales

Lire

Claude lit vos fichiers et comprend le code/contenu existant.

Tapez @ puis le début du nom du fichier (autocomplétion), ou donnez son chemin.

Écrire

Claude crée de nouveaux fichiers (code, config, docs).

Validez les chemins et permissions avant génération.

Modifier

Claude met à jour vos fichiers (corrections, améliorations).

Les changements sont intelligents et minimaux (pas de réécriture complète).

Répertoire de travail

Claude travaille relativement à votre répertoire courant pwd. Toujours utiliser des chemins explicites.

La mémoire : gestion du contexte

Claude dispose d'une fenêtre de contexte limitée. Quand elle se remplit, Claude Code résume automatiquement la conversation ; vous pouvez aussi le faire vous-même.

Quand utiliser /compact

  • Vous avez terminé une phase et en commencez une nouvelle sur le même sujet
  • Les réponses perdent le fil des consignes du début
  • Vous voulez choisir ce que le résumé garde : /compact garde les décisions sur le barème

Fonctionnement de /compact

$ /compact [Claude résume la conversation précédente] [Le résumé remplace l'historique détaillé] [Conversation continue avec mémoire compacte]

Nouveau sujet ? Préférez /clear : une conversation neuve coûte moins qu'un résumé.

Conseil : Utilisez /compact régulièrement pour maintenir une session fluide et économique.

  • Transférable : Mêmes concepts sur Codex, Antigravity, autres agents
