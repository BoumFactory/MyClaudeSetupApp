Ce que fait l'agent, en quatre étapes

1. Partir
De votre cours LaTeX converti, ou d'un document modèle qui compile
2. Écrire
Avec les encadrés de la suite farfadet, sans inventer une seule option
3. Compiler
Les versions professeur et élève, d'un seul coup

Les pages des deux versions, avant de vous les rendre

Vous intervenez au début (la demande) et à la fin (la relecture). Tout se fait dans le dossier que vous indiquez.

Il part de votre document, ou d'un modèle

Ce que fait l'agent

  • Votre cours LaTeX bfcours : il le convertit en Typst, commande par commande.
  • Un document neuf : il ouvre le modèle du même type (cours, fiche, évaluation, QCM) et en reprend la structure.
  • Un document LaTeX d'une autre origine : il l'adapte, après vous avoir posé les seules questions utiles.

Ce que vous y gagnez

  • Vos fichiers LaTeX ne sont jamais modifiés.
  • Le document arrive dans le dossier que vous indiquez, images comprises.
  • Il compile dès le départ : il ne reste que des retouches.

1. Partir Détail 1 / 3

La préconversion d'un .tex bfcours : une commande

python convertir.py "Vecteurs.tex" -o "Vecteurs/" --compiler
  • Chaque commande bfcours devient la fonction de même nom, écrite en minuscules à tirets ; chaque option devient une clé, vérifiée dans l'index de la suite.
  • Les formules passent en mode maths Typst ; les tableaux de variations en tabvar ; les minipages en colonnes.
  • Les figures TikZ restent en LaTeX, dans un extrait #latex[…] rendu à la compilation : fidèles par construction.
  • Ce qui ne compile pas est replié puis réparé, jusqu'à 60 tours.
LaTeX bfcoursTypst farfadet
\Definition#definition
\begin{EXO}#exo
\MultiColonnes#multi-colonnes
\tcbitempoint{2}#itempoint(2)
\ifcorrection A \else B \fi#ifcorrection[A][B]
figure TikZextrait #latex[…]
Demande de conversion seule : un appel, puis l'agent s'arrête et répond en trois lignes (fichiers produits, nombre de pages, points à reprendre).

1. Partir Détail 3 / 3

Une source qui n'est pas écrite avec bfcours

Il ne pose que les questions dont la réponse manque

  • La source suit-elle bfcours (si le préambule ne le dit pas) ?
  • Les figures : garder le dessin LaTeX (défaut) ou le redessiner en Typst ?
  • Faut-il une version élève, en plus de la version professeur ?

Sans réponse : contenu adapté aux encadrés farfadet (un théorème devient une propriété, un exercice un exo…), figures gardées en LaTeX, deux versions.

Comment il s'organise

  • Le travail est confié à un sous-agent de modèle intermédiaire quand l'outil le permet ; un sous-agent par grande partie pour un long document, puis un assemblage.
  • Consigne donnée : partir du modèle du même type, chercher chaque fonction, compiler les deux versions, lister ce qui a été interprété.
  • Le convertisseur automatique n'est pas utilisé : sur une source non bfcours, il ne produirait que du texte brut.

2. Écrire Détail 1 / 3

Ce qu'il écrit réellement dans le .typ

#import "@preview/farfadet:0.2.0": *
#show: modele("cours", niveau: "2nde",
  theme: [Vecteurs du plan], type-document: "cours")

= Repérage dans le plan
#definition[Repère][Un repère du plan est
  la donnée de trois points non alignés.]
#exo(level: 1)[Une équation][
  Résoudre $3 x + 5 = 17$.
  #crep(extra-lines: 1)[$3 x = 12$, donc $x = 4$.]
  #exocorrection
  $3 x = 12$, donc $x = 4$.
]
#ifcorrection[#rdexocorrection(0)]  // corrigés : prof seulement
  • modele(…) : l'en-tête (niveau, thème, type de document).
  • definition[titre][corps] : un encadré de cours.
  • exo : énoncé et corrigé, séparés par #exocorrection.
  • crep[…] : la réponse, en couleur chez le professeur ; chez l'élève, la même place, vide.
  • ifcorrection[prof][élève] : ce qui change d'une version à l'autre.

Avant un document d'un type courant, l'agent ouvre le modèle complet correspondant dans recettes/.

Personnaliser sans casser

  • Un seul réglage par paquet (setbfenvironments, setrdexo, setbfcolors…).

  • Une clé inconnue arrête la compilation et liste les possibilités.
Établissement, nom, logo, en-tête dans tous vos documents : l'agent suit une procédure dédiée (« façade »).

1. Partir2. Écrire3. Compiler4. Regarder

Il compile les deux versions d'un coup

Ce que fait l'agent

  • Un seul fichier donne la version professeur (réponses en couleur, corrigés) et la version élève (mêmes places, vides).
  • Les figures gardées en LaTeX sont rendues, puis mises de côté pour les compilations suivantes.
  • Sur une erreur, il lit le fichier, la ligne et la colonne, corrige et recompile.

Ce que vous y gagnez

  • Les mêmes PDF que ceux que VS Code produit chez vous.
  • Une à dix secondes par compilation : l'agent compile souvent, par petits morceaux.
  • Un seul fichier à tenir à jour, au lieu d'un maître professeur et d'un maître élève.

3. Compiler Détail 1 / 2

Un fichier, deux PDF : votre dossier après compilation

Vecteurs/ ├── vecteurs.typ le document ├── vecteurs-prof.pdf réponses, corrigés ├── vecteurs-eleve.pdf mêmes places, vides ├── images/ copiées de la source ├── rendus-tex/ extraits LaTeX rendus └── .apercu/ images de contrôle
python compiler.py "Vecteurs/vecteurs.typ" --png
  • Tout reste dans votre dossier : rien ne passe par un dossier temporaire, et rien n'est créé à côté de la source si vous avez demandé un autre dossier.
  • --version eleve : une seule version. Un chapitre inclus : le document maître est retrouvé.
  • rendus-tex/ est gardé : c'est la mémoire des extraits LaTeX. .apercu/ est retiré à la fin (--nettoyer).

Ce que seule l'image révèle

  • Une question séparée de sa zone de réponse par un saut de page : il réserve la place avant l'exercice.
  • Deux bandeaux de chapitre sur la même page : le second passe en tête de la page suivante.
  • Des formules minuscules : les polices n'ont pas été transmises, il recompile par le script.
  • Les calages du LaTeX (espaces négatifs, sauts de page forcés) ne sont pas recopiés : la mise en page se règle sur l'image Typst.

Une compilation réussie ne dit rien d'un débordement, d'une réponse visible chez l'élève ou d'une figure vide : d'où cette étape.

Ce que vous obtenez

Deux PDF
Professeur et élève, relus page par page, prêts à imprimer ou à projeter.
Le fichier Typst
Dans votre dossier : aperçu en direct dans VS Code, retouches à la main.
Des retouches en français

Votre rôle : demander, puis relire. Le contenu reste le vôtre, vérifiez-le comme le travail d'un collègue.

Limites, et où aller ensuite

Limites

  • La relecture porte sur le rendu : l'exactitude mathématique reste à vérifier par vous.
  • Un document LaTeX qui n'est pas en bfcours se convertit à la main, par l'agent : plus long, et il liste ce qu'il a interprété.
  • Les figures ne sont redessinées en Typst que sur demande : l'extrait LaTeX, fidèle, demande LaTeX sur le poste.
  • La suite farfadet est en préversion 0.2.0 : son interface peut encore évoluer.

Sur ce site

  • Packages Typst : installer la suite en une commande, la documentation, les 25 paquets.
  • Vidéo de prise en main de l'application Écriture Typst (3 min 49).

L'installer

Sur la page de cette présentation, ajoutez le pack « Skill Typst » au panier, puis téléchargez l'archive.

Claude Code, dans le projet recommandé
Décompresser dans le dossier du projet : les skills arrivent dans .claude/skills/.
Claude Code, global déconseillé
Dans ~/.claude/skills/ : actif partout, même là où il n'a rien à faire.
Codex, dans le projet recommandé
Copier le contenu de .claude/ dans .agents/ : les skills arrivent dans .agents/skills/.
Codex, global déconseillé
Dans ~/.agents/skills/.

Prérequis : la suite farfadet (une commande, page Packages Typst), Python et son module typst. VS Code et LaTeX sont facultatifs. Puis demandez simplement : « passe ce cours en Typst, avec la version élève ».
