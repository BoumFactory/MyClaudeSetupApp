Le skill programmes-officiels

Un skill Claude pour rechercher et citer les programmes officiels

  • Recherche précise dans les Bulletins Officiels (BO)
  • Citations exactes des programmes, du CM1 à la Terminale
  • Référencement des compétences attendues
  • Preuve visuelle : PDF, page et image de la page du BO

Structure des programmes officiels

Les programmes sont organisés de manière hiérarchique

  • Thèmes : grandes catégories mathématiques (Nombres et calculs, Géométrie, etc.)
  • Attendus de fin d'année/cycle : objectifs généraux
  • Connaissances et compétences : détail des notions
  • Exemples d'activités : suggestions pédagogiques

Workflow d'utilisation

1
Demander en français : « Que dit le programme de 4e sur les fractions ? »
2
Rechercher : Claude lance search.py (recherche plein texte, filtrée par niveau)
3
Détailler une compétence avec get.py : intitulé, formulation exacte du BO, page
4
Citer avec la preuve : PDF du BO, numéro de page, image de la page

Exemple de recherche

python scripts/search.py --keyword "fraction*" --niveau 4E

Comment la base est construite

Des scripts Python lisent les PDF du BO. Aucune IA ne recopie le texte officiel.

1
Découpage du PDF en pages (texte, PDF et image de chaque page)
2
Extraction des puces du BO, mot pour mot
3
Un fichier JSON par niveau : la source de vérité
4
Index de recherche, miroir Markdown et graphe des progressions

Appuyez sur ↓ pour voir une compétence

Format d'une compétence

{
  "code": "2GT-NB-008",
  "intitule": "Démonstration : √2 est irrationnel",
  "niveau": "2GT",
  "domaine": "NB",
  "type": "demonstration",
  "formulation_bo": "Le nombre réel √2 est irrationnel.",
  "prerequis": ["2GT-NB-003", "2GT-LOG-003"],
  "source": {"pdf": "2gt.pdf", "page": 7,
             "page_image": "../pages/2GT/page_007.png"},
  "tags": ["démonstration", "absurde", "irrationnel", "exigible"]
}

Cinq types : contenu, capacite, demonstration, algorithme, approfondissement

Nouveau BO ? Mise à jour

Remplacer le PDF dans data/pdf/, puis relancer les scripts de scripts/build/.

python scripts/validate.py
python -m pytest tests/

Structure du skill

.claude/skills/programmes-officiels/
├── SKILL.md                 # Instructions pour Claude
├── scripts/
│   ├── search.py            # Recherche plein texte
│   ├── get.py               # Détail d'une compétence
│   ├── demos.py · algos.py  # Démonstrations, algorithmes
│   ├── progression.py       # Une notion de niveau en niveau
│   ├── compare.py · stats.py
│   └── build/               # Construction depuis les PDF
└── data/
    ├── pdf/                 # 9 PDF officiels du BO
    ├── pages/               # Image de chaque page (preuve)
    ├── json/                # Un fichier par niveau (source de vérité)
    ├── markdown/            # Miroir lisible, généré
    └── search_index.sqlite  # Index de recherche

Conseils pratiques

  • Citations exactes
    pour documents officiels (inspecteurs)
  • Reformulation possible
    entre collègues (garder la référence)
  • Vérifier la date du BO
    les programmes évoluent
  • Exemples indicatifs
    les activités suggérées ne sont pas obligatoires
  • Donner la page
    PDF et numéro de page pour toute citation
  • Utiliser les codes
    pour traçabilité automatisée
