Ce que fait l'agent, en quatre étapes

1. Chercher
Il trouve dans le programme du niveau les compétences, démonstrations et algorithmes qui vous concernent
programmes-officiels
2. Citer
Il recopie la formulation du BO mot pour mot, avec le PDF et la page d'où elle vient
programmes-officiels
3. Construire
Il prépare la fiche du niveau, puis répartit avec vous les compétences en séquences
progression-builder
4. Vérifier
Il contrôle chaque code, signale les doublons et compte ce qui est placé sur le total du programme
progression-builder

Vous choisissez les séquences et leur ordre ; l'agent garantit que tout vient du BO et que rien n'est oublié.

Ce qu'il écrit : un petit fichier, pas la page entière

{
  "niveau": "5E",
  "elements": [
    { "type": "sequence",
      "titre": "Séquence 1 — Repérage dans le plan",
      "contenu": [
        { "type": "commentaire", "titre": "Période 1",
          "texte": "Du 1er septembre au 17 octobre." },
        { "type": "objectif", "code": "5E-GEO-001" },
        { "type": "separateur", "label": "Exos / RdP" }
      ] },
    { "type": "vacances", "label": "Vacances de la Toussaint" }
  ]
}
  • Une fiche pèse plusieurs centaines de kilo-octets (BO embarqué) : l'agent ne la charge pas, il décrit la progression dans ce JSON de quelques lignes.
  • Cinq éléments possibles : séquence, objectif, commentaire, séparateur, vacances.
  • Le même format sort du bouton JSON de la fiche : une progression remplie à la souris peut être reprise par l'agent.

4. Vérifier Détail 2 / 2

La fiche entre vos mains : tout se règle à la souris

Dans le navigateur, sans installation

  • Ouvrir la fiche que l'agent livre déjà remplie, ou Importer une progression JSON validée dans une fiche vierge.
  • Glisser-déposer les compétences ; le compteur indique combien restent à placer.
  • Ajouter séquences, séparateurs, commentaires ; plier, déplier.
  • Double-cliquer sur une compétence : le BO s'ouvre à la bonne page.

Pour la garder et la partager

  • HTML : enregistrer la fiche remplie.
  • PDF : l'imprimer, colonne de gauche masquée.
  • JSON : la redonner à l'agent pour la retoucher.
  • Dans la configuration : export Markdown et LaTeX, couleurs des séquences.

Ce que vous obtenez

La fiche de progression
Vos séquences et vos vacances, à compléter, imprimer ou exporter. Treize fiches vierges, du CM1 à la Terminale, sont déjà fournies pour vos collègues.

Des retouches en français

Votre rôle : décider de l'ordre et du découpage. La progression reste la vôtre ; l'agent garantit qu'elle respecte le BO.

Limites

À savoir

  • La base suit les programmes de la rentrée 2026 ; un autre BO demande de la reconstruire.
  • Le lien entre compétences (prérequis) n'est pas encore renseigné : la progression d'une notion se fait par recherche, pas par un graphe.
  • La recherche porte sur les mots du BO : un synonyme absent du texte ne trouve rien ; l'agent reformule.

Dans la fiche

  • Dans une séquence, les commentaires s'affichent sous les compétences ; un séparateur « Exos / RdP » placé au milieu devient un commentaire.
  • Une compétence ne se place qu'une fois : un doublon dans la progression est signalé puis ignoré.

L'installer

Sur la page de cette présentation, ajoutez le pack « Skills programmes et progression » au panier, puis téléchargez l'archive.

Claude Code, global déconseillé
Dans ~/.claude/skills/ : actifs partout, même là où ils n'ont rien à faire.
Codex, dans le projet recommandé
Copier le contenu de .claude/ dans .agents/ : les skills arrivent dans .agents/skills/.
Codex, global déconseillé
Dans ~/.agents/skills/.

Prérequis : Python 3, sans module à installer, et un navigateur pour la fiche. Gardez les deux skills côte à côte. Puis demandez : « construis ma progression de 5e en sept séquences ».
