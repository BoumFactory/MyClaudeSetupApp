Activité-Timer

Un minuteur qui se superpose au document projeté pour rythmer recherche et correction.

Version 0.1.0 — exécutable Windows 10 ou 11, 64 bits — 5,4 Mo — à lancer directement, sans installation.

Télécharger le zip

Ce qu'il fait en classe

  • Une fenêtre flottante, toujours au premier plan, se pose sur votre PDF ou votre page projetée sans lui voler le focus.
  • Deux phases explicites, résolution puis correction, avec changement de couleur et jauge.
  • Préréglages de 1, 3, 5, 10, 15 et 20 minutes ; au clavier : Espace pour démarrer ou mettre en pause, touches 1 à 6 pour les préréglages, C pour passer à la correction, R pour remettre à zéro.
  • Une fenêtre de contrôle pour l'enseignant, avec un aperçu de ce que voit la classe.

Premier lancement

  1. Décompressez le zip dans un dossier où vous avez le droit d'écrire (par exemple vos Documents) : il crée un dossier Activite-Timer avec activite-timer.exe et ce mode d'emploi.
  2. Double-cliquez sur activite-timer.exe. Aucun droit d'administrateur n'est nécessaire.
  3. Choisissez une durée et lancez.

Vos données

Vos réglages restent sur votre poste, dans les dossiers config et assets créés à côté de l'exécutable. Aucune connexion n'est utilisée.

L'avertissement de Windows

  • L'exécutable n'est pas signé : Windows SmartScreen affiche « Windows a protégé votre ordinateur ». Cliquez sur Informations complémentaires, puis Exécuter quand même.
  • Sous Windows 11, si le contrôle intelligent des applications (Smart App Control) est activé, une application non signée est bloquée, sans possibilité de l'autoriser au cas par cas.
  • L'application a besoin du composant WebView2 de Microsoft, présent sur Windows 10 et 11 à jour. S'il manque, la fenêtre ne s'ouvre pas : installez le « runtime WebView2 » depuis le site de Microsoft.
