Gestion de classes

Plan de classe interactif et rôles des élèves, à piloter en direct pendant la séance.

Version 0.1.0 — exécutable Windows 10 ou 11, 64 bits — 12,3 Mo — à lancer directement, sans installation.

Télécharger le zip

Ce qu'il fait en classe

  • Import des listes d'élèves par classe depuis un fichier CSV (enregistré depuis un tableur).
  • Plan de classe sur grille : on place et on déplace les élèves, avec l'historique des plans.
  • Rôles de classe (délégué, éco-délégué… ou rôles personnalisés) attribués et répartis équitablement au fil des séances.
  • Mode « Je suis en séance » et emploi du temps sommaire pour retrouver la classe en cours.

Premier lancement

  1. Décompressez le zip dans un dossier où vous avez le droit d'écrire (par exemple vos Documents) : il crée un dossier Gestion-de-classes avec gestion-classes.exe et ce mode d'emploi.
  2. Double-cliquez sur gestion-classes.exe : l'application démarre vide, aucune classe n'est fournie.
  3. Importez un fichier CSV par classe. La première ligne nomme les colonnes : au moins « nom » et « prénom », et si vous le souhaitez « id » et « sousGroupe ». Le séparateur peut être la virgule ou le point-virgule. Exemple avec des élèves fictifs : 
    prenom;nom;sousGroupe
Alice;Martin;Groupe 1
Lucas;Bernard;Groupe 2
  4. Activez ensuite les rôles prédéfinis ou créez les vôtres.

Vos données

Vos données restent sur votre poste : de simples fichiers CSV et JSON, dans un dossier data créé à côté de l'exécutable. Aucun compte, aucune connexion. Pour sauvegarder ou changer de poste, copiez l'exécutable avec son dossier data. Seules les préférences d’affichage (dernière classe ouverte, taille de la grille) sont gardées par Windows dans votre profil. Ces fichiers contiennent les noms de vos élèves : rangez-les dans un dossier personnel, pas sur une clé ou un espace partagé.

L'avertissement de Windows

  • L'exécutable n'est pas signé : Windows SmartScreen affiche « Windows a protégé votre ordinateur ». Cliquez sur Informations complémentaires, puis Exécuter quand même.
  • Sous Windows 11, si le contrôle intelligent des applications (Smart App Control) est activé, une application non signée est bloquée, sans possibilité de l'autoriser au cas par cas.
  • L'application a besoin du composant WebView2 de Microsoft, présent sur Windows 10 et 11 à jour. S'il manque, la fenêtre ne s'ouvre pas : installez le « runtime WebView2 » depuis le site de Microsoft.
