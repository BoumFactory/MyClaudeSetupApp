Exos Lombards

Composer des fiches d'exercices, des devoirs et des sujets au format bac à partir de vos propres exercices LaTeX.

Version 0.1.0 — exécutable Windows 10 ou 11, 64 bits — à lancer directement, sans installation.

Télécharger l'application et son kit (zip)

Ce qu'il fait

  • Compose des fiches d'exercices, des devoirs avec barème et des sujets au format bac, compilés en PDF, avec les corrigés en fin de document ou dans un second fichier.
  • Importe vos fichiers LaTeX (environnement EXO de bfcours, paires énoncé et corrigé…) pour constituer vos propres bases d'exercices, classées par thèmes.
  • Accepte des exercices libres, écrits directement en LaTeX, avec un aperçu compilé.
  • Garde, pour chaque classe, la trace des exercices déjà donnés, et produit des catalogues PDF de vos bases.

Ce que contient le zip

Un dossier Exos-Lombards avec :

  • exos-lombards.exe, l'application ;
  • .exoslombards, le kit de départ : les modèles de documents (fiche, devoir, sujet bac), le préambule commun et une copie du paquet LaTeX bfcours. Aucune banque d'exercices n'est fournie : l'application démarre avec « 0 exercice ».

Ces deux éléments doivent rester côte à côte : le dossier .exoslombards doit se trouver dans le même dossier que exos-lombards.exe.

Prérequis

  • LuaLaTeX, par MiKTeX (recommandé) ou TeX Live. Au premier document, MiKTeX installe à la volée les paquets qui lui manquent : gardez une connexion internet.
  • bfcours : si ce paquet n'est pas déjà installé sur votre poste, ouvrez Réglages, rubrique « bfcours embarqué », puis cliquez sur Installer bfcours dans MiKTeX. La copie fournie dans le kit est alors déclarée à MiKTeX. Avec TeX Live, l'application affiche la commande à lancer.
  • Tectonic, en secours seulement, si LuaLaTeX est absent : téléchargez tectonic.exe sur le site officiel de Tectonic et placez-le à côté de exos-lombards.exe. Tectonic refuse les chemins qui contiennent une espace.
  • Une connexion internet pour l'éditeur de code LaTeX (exercices libres, éditeur d'exercices), qui se charge en ligne.

Premier lancement

  1. Décompressez le zip dans un dossier dont le chemin ne contient aucune espace, par exemple C:\Applis\Exos-Lombards.
  2. Double-cliquez sur exos-lombards.exe.
  3. Dans Composer, remplacez le nom d'établissement proposé par celui de votre établissement.
  4. Premier document : Composer, bouton Exercice libre, collez un exercice LaTeX, par exemple : 
    \begin{EXO}{Premier essai}{ESSAI}
Calculer $2+3$.
\exocorrection
$2+3=5$.
\end{EXO}
    puis Ajouter au panier, Retour au Composer et Produire le document.
  5. Pour constituer une base, passez par l'onglet Importer avec vos propres fichiers LaTeX.

L'écran Aide de l'application est vide dans cette distribution : ce mode d'emploi le remplace.

Vos données

Tout reste sur votre poste, dans le dossier .exoslombards à côté de l'exécutable : vos bases, vos fiches, vos classes et vos réglages. Aucun compte, aucun envoi. Pour sauvegarder ou changer de poste, copiez le dossier Exos-Lombards entier.

L'avertissement de Windows

  • L'exécutable n'est pas signé : Windows SmartScreen affiche « Windows a protégé votre ordinateur ». Cliquez sur Informations complémentaires, puis Exécuter quand même.
  • Sous Windows 11, si le contrôle intelligent des applications (Smart App Control) est activé, une application non signée est bloquée, sans possibilité de l'autoriser au cas par cas.
  • L'application a besoin du composant WebView2 de Microsoft, présent sur Windows 10 et 11 à jour. S'il manque, la fenêtre ne s'ouvre pas : installez le « runtime WebView2 » depuis le site de Microsoft.
