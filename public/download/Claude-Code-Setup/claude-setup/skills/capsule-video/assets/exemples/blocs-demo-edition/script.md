# Script — démonstration de l'édition de code (remplace, efface, insere)

## Choix didactiques

- Séquence de 8 s : une seule ligne Typst, `correction-color`, change de valeur trois fois sous les yeux de l'élève, et le rendu à droite change avec elle.
- Chaque geste est calé sur un mot dit ; le geste `compile` fait basculer l'image de rendu en fondu.
- b01 : prop est effacé lettre à lettre, monrose est tapé, compilation, rendu rose.
- b02 : monrose est sélectionné puis remplacé par red, compilation, rendu rouge.
- b03 : red redevient prop, compilation, rendu d'origine.

## b01 [pause 0.25]
D'abord, rose.

## b02 [pause 0.25]
Ensuite, rouge.

## b03 [pause 0.5]
Et on revient à la valeur de départ.
