# Activité « De la translation au vecteur » (2nde) : specs

Une activité de découverte en deux séances de 55 minutes, en LaTeX bfcours, qui ouvre le chapitre « Vecteurs du plan (1) » de la seconde, pour le professeur et ses élèves.

Statut : prêt à construire

## Avant toute tâche

Lire `00-vision.md` (2 minutes). Les choix déjà faits sont dans `05-decisions.md` : ne pas les remettre en cause sans l'utilisateur.

## Où trouver quoi

| Tâche | Fichiers à lire |
|---|---|
| Comprendre le besoin | `00-vision.md`, `01-usages.md` |
| Questions, figures, réponses attendues, minutage | `02-contenu.md` |
| Construire un lot | `07-plan-de-construction.md` (le lot), puis les fichiers que ce lot cite |
| Format, mise en page, fichiers livrés, compilation | `03-forme.md`, `05-decisions.md` |
| Vérifier une livraison | `04-criteres-acceptation.md` |
| Une demande hors du plan | `06-perimetre.md` d'abord |

## Règles pour l'agent constructeur

- Charger les skills `bfcours-latex` et `latex-geometry` avant d'écrire du LaTeX.
- Ne jamais modifier le cours P1 (`1. Cours/2nde/Sequence-Vecteur_par_coordonnees-P1/Cours/`) : il se lit, pour les notations et le vocabulaire (D-06, D-08, D-11).
- Aucune rédaction LaTeX avant la validation du déroulé par l'utilisateur (lot 1, D-12).
- Rester dans le périmètre du CH1 : pas de somme, pas de produit par un réel, pas de coordonnées de vecteur (`06-perimetre.md`).
- Ne jamais toucher au dossier « 2. Administratif ».
- Une nouvelle décision essentielle se pose à l'utilisateur. Une décision secondaire se note dans `05-decisions.md` avec le statut « par défaut ».
