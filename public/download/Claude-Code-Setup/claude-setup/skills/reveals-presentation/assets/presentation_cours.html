Qu'est-ce qu'un monôme ?

Question : Comment définir un monôme ?

Appuyez sur ↓ pour la définition

Définition

Monôme : Expression algébrique formée du produit d'un coefficient \(a\) réel par une puissance (entière) d'une indéterminée \(X\) :

\[aX^n\]

Exemples :

  • \(4X^0 = 4\)
  • \(-3X^1 = -3X\)
  • \(\pi X^2\)
  • \(12{,}5X^7\)
Remarque sur le degré ↓

Degré d'un monôme

L'exposant de \(X\) est appelé le degré du monôme.

Exemples :

  • \(-3X\) est de degré 1
  • \(\pi X^2\) est de degré 2
  • \(12{,}5X^7\) est de degré 7
  • \(4\) est de degré 0
  • \(0X = 0\) est de degré \(-\infty\)
FAQ ↓

💡 Questions fréquentes

Q : Pourquoi utilise-t-on \(X\) majuscule et non \(x\) minuscule ?

R : \(X\) désigne une indéterminée (variable abstraite), tandis que \(x\) désignera une variable numérique dans les applications. Cette distinction sera importante plus tard !

Qu'est-ce qu'un polynôme ?

Question : Comment passe-t-on des monômes aux polynômes ?

Appuyez sur ↓ pour la définition

Définition

Polynôme : Une somme (finie) de monômes.

Exemple :

\[-3 + 8X^2 + 4X - 7X^3 - 7X + 10\]

Ce polynôme contient 6 monômes.

Forme réduite ↓

Forme réduite

Polynôme réduit : Tous ses monômes sont de degrés distincts.

Exemple :

  • \(3X^2 - 12X^5 + 2\) est réduit ✓
  • \(5 + 7X - 14X^2 + 8X\) n'est pas réduit ✗
    (car \(7X\) et \(8X\) sont semblables)
Comment réduire ? ↓

💡 Comment réduire ?

Q : Comment réduire \(5 + 7X - 14X^2 + 8X\) ?

R : Regrouper les termes de même degré :

\[\begin{align} 5 + 7X - 14X^2 + 8X &= 5 + (7X + 8X) - 14X^2 \\ &= 5 + 15X - 14X^2 \end{align}\]

\(5 + 15X - 14X^2\)

Forme ordonnée

Polynôme ordonné : Polynôme réduit dont les monômes sont rangés suivant les puissances décroissantes de \(X\).

Exemples ↓

Exemples

  • \(-7X^3 + X - 3\) est ordonné ✓
  • \(X - 7X^2 + 2\) n'est pas ordonné ✗

Correction :

\[X - 7X^2 + 2 = -7X^2 + X + 2\]

Erreur fréquente ↓

⚠️ Erreur fréquente

Attention ! L'ordre des puissances est décroissant, pas croissant !

❌ Faux : \(2 + X - 7X^2\) (ordre croissant des puissances)

✓ Correct : \(-7X^2 + X + 2\) (ordre décroissant des puissances)

Pourquoi développer ?

Problème : Est-ce que \(x^2(3x-1)\) est un polynôme ?

A priori non ! Ce n'est pas une somme de monômes...

Mais en distribuant \(x^2\), on peut le transformer !

Développement détaillé ↓

Développement de \(x^2(3x-1)\)

Étape 1 : On distribue \(x^2\)

\[x^2(3x-1) = x^2\times 3x - x^2\times 1\]

Étape 2 : On simplifie \(x^2 \times 1\)

\[= x^2\times 3x^1 - x^2\]

Étape 3 : On applique la règle des exposants

\[= 3x^{2+1} - x^2\]

Étape 4 : Résultat final

\[3x^3 - x^2\]

Ainsi \(x^2(3x-1) = 3x^3 - x^2\) est bien un polynôme de degré 3 !

Convention ↓

Convention d'écriture

Afin d'identifier chaque polynôme, la convention est de l'écrire sous forme :

  • Développée : Uniquement des sommes de monômes
  • Réduite : tous les monômes de degrés distincts
  • Ordonnée : puissances décroissantes

Pourquoi cette convention ?

Pour pouvoir comparer deux polynômes, on les met sous cette forme puis on compare les coefficients associés aux mêmes puissances.

Définition d'égalité ↓

Égalité de polynômes

Définition :

Deux polynômes sont dits égaux lorsqu'ils ont la même expression développée, réduite et ordonnée.

Exemple :

Les polynômes \(x^2(3x-1)\) et \(3x^3-x^2\) sont égaux car :

\[\begin{align} x^2(3x-1) &\text{ (forme factorisée)} \\ &= 3x^3 - x^2 \text{ (forme développée, réduite, ordonnée)} \end{align}\]

Conséquence : Pour vérifier si deux polynômes sont égaux, on les développe, réduit et ordonne, puis on compare terme à terme.

Distributivité

\[a(b+c) = ab + ac\]

Propriété fondamentale pour développer une expression.

Exemple ↓

Exemple : Développer \(3(x+2)\)

On applique la distributivité :

\[3(x+2) = 3 \times x + 3 \times 2\]

On simplifie :

\(3x + 6\)
Erreur courante ↓

⚠️ Erreur fréquente

Oublier de distribuer au 2ème terme

❌ Faux : \(3(x+2) = 3x + 2\)

(Le 3 n'a pas été distribué au 2)

✓ Correct : \(3(x+2) = 3x + 6\)

FAQ ↓

💡 Questions fréquentes

Q : Pourquoi doit-on distribuer ?

R : C'est une propriété axiomatique des nombres réels : la multiplication est distributive sur l'addition. Cela permet de transformer un produit en somme.

Double distributivité

\[(a+b)(c+d) = ac + ad + bc + bd\]

Chaque terme du 1er facteur avec chaque terme du 2nd.

Exemple ↓

Exemple : Développer \((x+2)(x+3)\)

On applique la double distributivité :

\[(x+2)(x+3) = x \times x + x \times 3 + 2 \times x + 2 \times 3\]

On simplifie :

\[= x^2 + 3x + 2x + 6\]

On réduit :

\(x^2 + 5x + 6\)
Méthode visuelle ↓

Méthode "chaque avec chaque"

\((x+2)(x+3)\)

  • 1️⃣ \(x \times x = x^2\)
  • 2️⃣ \(x \times 3 = 3x\)
  • 3️⃣ \(2 \times x = 2x\)
  • 4️⃣ \(2 \times 3 = 6\)

Somme : \(x^2 + 3x + 2x + 6 = x^2 + 5x + 6\)

Erreur courante ↓

⚠️ Erreur à éviter

Oublier les termes croisés

❌ Faux : \((x+2)(x+3) = x^2 + 6\)

(Les termes \(3x\) et \(2x\) ont été oubliés)

✓ Correct : \((x+2)(x+3) = x^2 + 5x + 6\)

Identité remarquable : \((a+b)^2\)

\[(a+b)^2 = a^2 + 2ab + b^2\]

Formule à connaître par cœur !

Exemple ↓

Exemple : Développer \((x+3)^2\)

On identifie : \(a = x\) et \(b = 3\)

On applique la formule :

\[(x+3)^2 = x^2 + 2 \times x \times 3 + 3^2\]

On simplifie :

\(x^2 + 6x + 9\)
Astuce mnémotechnique ↓

💡 Astuce pour retenir

Structure :

  1. Carré du 1er : \(a^2\)
  2. Double produit : \(2ab\)
  3. Carré du 2ème : \(b^2\)

Phrase : "Carré du premier, plus deux fois le produit, plus carré du second"

FAQ ↓

💡 Questions fréquentes

Q : Pourquoi \((x+3)^2 \neq x^2 + 9\) ?

R : On ne peut pas distribuer l'exposant ! Il faut utiliser la formule :

\[(x+3)^2 = (x+3)(x+3) = x^2 + 3x + 3x + 9 = x^2 + 6x + 9\]

Le terme \(6x\) est essentiel et souvent oublié !

Identité remarquable : \((a-b)^2\)

\[(a-b)^2 = a^2 - 2ab + b^2\]

Attention au signe du terme médian !

Exemple ↓

Exemple : Développer \((x-4)^2\)

On identifie : \(a = x\) et \(b = 4\)

On applique la formule :

\[(x-4)^2 = x^2 - 2 \times x \times 4 + 4^2\]

On simplifie :

\(x^2 - 8x + 16\)
Différence avec (a+b)² ↓

Comparaison : \((a+b)^2\) vs \((a-b)^2\)

\((a+b)^2\)

\(= a^2 \mathbf{+} 2ab + b^2\)

\((a-b)^2\)

\(= a^2 \mathbf{-} 2ab + b^2\)

Seul le terme médian change de signe !

Erreur courante ↓

⚠️ Erreur sur le signe

Confusion sur le signe du terme médian

❌ Faux : \((x-4)^2 = x^2 + 8x + 16\)

(Le signe du terme médian est incorrect)

✓ Correct : \((x-4)^2 = x^2 - 8x + 16\)

Identité remarquable : \(a^2-b^2\)

\[(a-b)(a+b) = a^2 - b^2\]

Différence de deux carrés

Exemple ↓

Exemple : Développer \((x-5)(x+5)\)

On identifie : \(a = x\) et \(b = 5\)

On applique la formule :

\[(x-5)(x+5) = x^2 - 5^2\]

On simplifie :

\(x^2 - 25\)
Reconnaissance visuelle ↓

Comment reconnaître cette formule ?

Indices visuels :

  • Produit de deux binômes
  • Mêmes termes dans les deux facteurs
  • Signes opposés : \((a\mathbf{-}b)(a\mathbf{+}b)\)

Résultat : Disparition des termes en \(x\), il ne reste que les carrés !

Calcul mental ↓

💡 Application au calcul mental

Q : Calculer \(103 \times 97\) sans calculatrice ?

R : On remarque que \(103 = 100 + 3\) et \(97 = 100 - 3\)

\[\begin{align} 103 \times 97 &= (100+3)(100-3) \\ &= 100^2 - 3^2 \\ &= 10\,000 - 9 \\ &= 9\,991 \end{align}\]

\(103 \times 97 = 9\,991\)

Exercice : Développement

★★☆ 3 minutes

Énoncé : Développer et réduire

\[(2x+1)(x-3)\]

Choix de méthode ↓

Choix de la méthode

Quelle formule utiliser ?

  • Distributivité simple ? Non (deux binômes)
  • Identité remarquable ? Non (signes différents)
  • Double distributivité ✓
Application ↓

Application de la double distributivité

Étape 1 : Chaque terme avec chaque terme

\[\begin{align} (2x+1)(x-3) &= 2x \times x + 2x \times (-3) \\ &\quad + 1 \times x + 1 \times (-3) \end{align}\]

Étape 2 : Simplification

\[= 2x^2 - 6x + x - 3\]

Étape 3 : Réduction

\[= 2x^2 - 5x - 3\]

Résultat final ↓

Résultat final

\[(2x+1)(x-3) = 2x^2 - 5x - 3\]

Vérification : L'expression est développée, réduite et ordonnée ✓

Qu'est-ce que factoriser ?

Question : Quelle est la définition de la factorisation ?

Définition ↓

Définition

Factoriser : Écrire une expression algébrique sous forme d'un produit.

Exemple :

\[3x + 6 = 3(x+2)\]

Forme développée → Forme factorisée (produit)

Utilité ↓

Pourquoi factoriser ?

La factorisation est utile pour :

  1. Simplifier un quotient
  2. Résoudre des équations

Exemple 1 : Simplifier \(\dfrac{3x+6}{3}\)

\[= \dfrac{3(x+2)}{3} = x+2\]

Exemple 2 : Résoudre \(x(x-2) = 0\)

\[x = 0 \text{ ou } x-2 = 0 \implies x = 0 \text{ ou } x = 2\]

FAQ ↓

💡 Questions fréquentes

Q : Quelle est la différence entre développer et factoriser ?

R :

  • Développer : Transformer un produit en somme
    \(3(x+2) \to 3x+6\)
  • Factoriser : Transformer une somme en produit
    \(3x+6 \to 3(x+2)\)

Ce sont des opérations inverses !

Facteur commun

\[ab + ac = a(b+c)\]

Première méthode à tester pour factoriser

Exemple ↓

Exemple : Factoriser \(3x+6\)

Étape 1 : Identifier les termes

Les termes sont : \(3x\) et \(6\)

Étape 2 : Écrire chaque terme comme produit

( Décompositions en produit de facteurs premiers )

\(3x = 3 \times x\) et \(6 = 3 \times 2\)

Étape 3 : Identifier le facteur commun

Facteur commun : 3

Étape 4 : Factoriser

\(3x + 6 = 3(x+2)\)
Méthode de détection ↓

Comment détecter un facteur commun ?

Méthode :

  1. Décomposer chaque coefficient en facteurs premiers
  2. Chercher les variables présentes dans tous les termes
  3. Prendre le PGCD des coefficients et la puissance minimale des variables

Exemple : \(12x^3 + 18x^2\)

  • PGCD(12, 18) = 6 Car \(6 \times 2 = 12\) et \(6 \times 3 = 18\)
  • Puissance min de \(x\) : \(x^2\)
  • Facteur commun : \(6x^2\)
\(12x^3 + 18x^2 = 6x^2(2x+3)\)
Erreur courante ↓

⚠️ Facteur incomplet

Oublier une partie du facteur commun

Pour \(12x^3 + 18x^2\) :

❌ Faux : \(= 6(2x^3+3x^2)\)

(On a oublié le \(x^2\) dans le facteur commun)

❌ Faux : \(= x^2(12x+18)\)

(On a oublié le 6 dans le facteur commun)

✓ Correct : \(= 6x^2(2x+3)\)

Identité remarquable : \(a^2+2ab+b^2\)

\[a^2 + 2ab + b^2 = (a+b)^2\]

Reconnaissance d'une somme au carré

Exemple ↓

Exemple : Factoriser \(x^2+6x+9\)

Étape 1 : Identifier les carrés

\(x^2 = (x)^2\) et \(9 = 3^2\)

Donc \(a = x\) et \(b = 3\)

Étape 2 : Vérifier le terme médian

\(2ab = 2 \times x \times 3 = 6x\) ✓

Étape 3 : Factoriser

\(x^2 + 6x + 9 = (x+3)^2\)
Reconnaissance ↓

Comment reconnaître \(a^2+2ab+b^2\) ?

Liste de vérification :

  1. Trois termes dans la somme
  2. Le 1er terme est un carré : \(a^2\)
  3. Le 3ème terme est un carré : \(b^2\)
  4. Le terme médian est \(2ab\) (vérifier !)
  5. Tous les signes sont positifs

Astuce : Pour vérifier le terme médian, calculer \(2 \times a \times b\) et comparer.

FAQ ↓

💡 Questions fréquentes

Q : Comment trouver \(a\) et \(b\) dans \(4x^2 + 12x + 9\) ?

R :

  • \(4x^2 = (2x)^2 \implies a = 2x\)
  • \(9 = 3^2 \implies b = 3\)
  • Vérification : \(2ab = 2 \times 2x \times 3 = 12x\) ✓
\(4x^2 + 12x + 9 = (2x+3)^2\)

Identité remarquable : \(a^2-2ab+b^2\)

\[a^2 - 2ab + b^2 = (a-b)^2\]

Reconnaissance d'une différence au carré

Exemple ↓

Exemple : Factoriser \(x^2-10x+25\)

Étape 1 : Identifier les carrés

\(x^2 = (x)^2\) et \(25 = 5^2\)

Donc \(a = x\) et \(b = 5\)

Étape 2 : Vérifier le terme médian

\(2ab = 2 \times x \times 5 = 10x\)

Le terme médian est \(-10x\) ✓

Étape 3 : Factoriser

\(x^2 - 10x + 25 = (x-5)^2\)
Différence avec \(a^2+2ab+b^2\) ↓

Comparaison des deux formules

\(a^2 \mathbf{+} 2ab + b^2\)

\(= (a\mathbf{+}b)^2\)

Terme médian positif

\(a^2 \mathbf{-} 2ab + b^2\)

\(= (a\mathbf{-}b)^2\)

Terme médian négatif

Règle : Le signe du terme médian détermine le signe dans la factorisation !

Erreur courante ↓

⚠️ Confusion de signe

Oublier le signe du terme médian

Pour \(x^2 - 10x + 25\) :

❌ Faux : \(= (x+5)^2\)

(Le signe dans la parenthèse est incorrect)

Car \((x+5)^2 = x^2 + 10x + 25 \neq x^2 - 10x + 25\)

✓ Correct : \(= (x-5)^2\)

Identité remarquable : \(a^2-b^2\)

\[a^2 - b^2 = (a-b)(a+b)\]

Différence de deux carrés

Exemple ↓

Exemple : Factoriser \(x^2-25\)

Étape 1 : Identifier les carrés

\(x^2 = (x)^2\) et \(25 = 5^2\)

Donc \(a = x\) et \(b = 5\)

Étape 2 : Vérifier la structure

Forme : \(a^2 - b^2\) ✓ (différence de deux carrés)

Étape 3 : Factoriser

\(x^2 - 25 = (x-5)(x+5)\)
Reconnaissance rapide ↓

Reconnaissance rapide de \(a^2-b^2\)

Indices visuels :

  • Seulement deux termes
  • Séparés par un signe moins
  • Chaque terme est un carré parfait

Exemples rapides :

  • \(x^2 - 4 = (x-2)(x+2)\)
  • \(9x^2 - 16 = (3x-4)(3x+4)\)
  • \(x^2 - 1 = (x-1)(x+1)\)
Application ↓

Application : \(4x^2-9\)

Analyse :

  • \(4x^2 = (2x)^2 \implies a = 2x\)
  • \(9 = 3^2 \implies b = 3\)

Application de la formule :

\[4x^2 - 9 = (2x)^2 - 3^2 = (2x-3)(2x+3)\]

\(4x^2 - 9 = (2x-3)(2x+3)\)

Démarche de factorisation

Stratégie en 4 étapes :

  1. Chercher un facteur commun
  2. Utiliser une identité remarquable
  3. Factoriser une partie pour faire apparaître un facteur commun ou une identité
  4. Développer et réessayer
Détail étape 1 ↓

Étape 1 : Facteur commun

Procédure :

  1. Identifier les termes de la somme (ou différence)
  2. Écrire chaque terme sous forme d'un produit
  3. Identifier un facteur commun à tous les termes
  4. Mettre le facteur en évidence

Si trouvé : Factoriser et recommencer sur ce qui reste dans la parenthèse

Si non : Passer à l'étape 2

Détail étape 2 ↓

Étape 2 : Identité remarquable

Quelle identité choisir ?

Structure Formule
3 termes, signes + \(a^2+2ab+b^2=(a+b)^2\)
3 termes, médian - \(a^2-2ab+b^2=(a-b)^2\)
2 termes, signe - \(a^2-b^2=(a-b)(a+b)\)
Détail étapes 3-4 ↓

Étapes 3 et 4 : Techniques avancées

Étape 3 : Factorisation partielle

Exemple : \(x^3-x = x(x^2-1) = x(x-1)(x+1)\)

On factorise d'abord \(x\), puis on reconnaît \(a^2-b^2\) dans le reste

Étape 4 : Développer et réessayer

Si vraiment rien ne marche, développer complètement puis recommencer

Cette étape fonctionne rarement, mais peut révéler des structures cachées

Exercice : Factorisation

★★☆ 4 minutes

Énoncé : Factoriser

\[2x^2 - 8\]

Étape 1 ↓

Étape 1 : Facteur commun

Analyse :

  • Termes : \(2x^2\) et \(8\)
  • - PGCD(2, 8) = 2
  • - Facteur commun : 2

Factorisation :

\[2x^2 - 8 = 2(x^2 - 4)\]

Attention : On n'a pas fini ! Il faut continuer avec \(x^2 - 4\)

Étape 2 ↓

Étape 2 : Identité remarquable

Analyse de \(x^2 - 4\) :

  • 2 termes séparés par un signe -
  • \(x^2 = (x)^2\) et \(4 = 2^2\)
  • C'est une différence de carrés ! \(a^2-b^2\)

Application de la formule :

\[x^2 - 4 = (x-2)(x+2)\]

Factorisation complète :

\[2x^2 - 8 = 2(x-2)(x+2)\]

Vérification ↓

Vérification par développement

Développons \(2(x-2)(x+2)\) :

Étape 1 : \((x-2)(x+2)\)

\[(x-2)(x+2) = x^2 - 4\]

Étape 2 : Multiplier par 2

\[2(x^2-4) = 2x^2 - 8\]

On retrouve bien l'expression initiale ✓

\[2x^2 - 8 = 2(x-2)(x+2)\]

Exercice : Cas complexe

★★★ 5 minutes

Énoncé : Factoriser

\[(x+1)^2 - (2x-3)^2\]

Reconnaissance ↓

Reconnaissance de la structure

Analyse :

  • Forme : quelque chose² - quelque chose²
  • C'est une différence de carrés ! \(a^2 - b^2\)

Identification :

  • \(a = (x+1)\)
  • \(b = (2x-3)\)
Application formule ↓

Application de \(a^2-b^2=(a-b)(a+b)\)

On applique la formule :

\[(x+1)^2 - (2x-3)^2 = [(x+1) - (2x-3)][(x+1) + (2x-3)]\]

Simplification du 1er facteur :

\[\begin{align} (x+1) - (2x-3) &= x + 1 - 2x + 3 \\ &= -x + 4 \end{align}\]

Simplification du 2ème facteur :

\[\begin{align} (x+1) + (2x-3) &= x + 1 + 2x - 3 \\ &= 3x - 2 \end{align}\]

Résultat final ↓

Résultat final

\[(x+1)^2 - (2x-3)^2 = (-x+4)(3x-2)\]

Forme alternative :

On peut aussi écrire (en factorisant -1) :

\[= -(x-4)(3x-2)\]

Remarque : Cette méthode évite de développer les carrés, ce qui serait beaucoup plus long !

Fractions et polynômes

Les règles d'opérations sur les fractions s'appliquent également lorsque les numérateurs et dénominateurs sont des polynômes.

Rappels :

Multiplication

\[\dfrac{a}{b}\times \dfrac{c}{d}=\dfrac{a\times c}{b\times d}\]

Addition

\[\dfrac{a}{b}+ \dfrac{c}{d}=\dfrac{a\times d + b\times c}{b\times d}\]
Exemples ↓

Exemple : Multiplication

Calculer : \(\dfrac{x+2}{3} \times \dfrac{2}{x-1}\)

On applique la formule :

\[\dfrac{x+2}{3} \times \dfrac{2}{x-1} = \dfrac{(x+2) \times 2}{3 \times (x-1)}\]

On simplifie :

\[\dfrac{2(x+2)}{3(x-1)}\]
Exemple addition ↓

Exemple : Addition

Calculer : \(\dfrac{x}{2} + \dfrac{3}{x}\)

On réduit au même dénominateur \(2x\) :

\[\dfrac{x}{2} + \dfrac{3}{x} = \dfrac{x \times x}{2 \times x} + \dfrac{3 \times 2}{x \times 2}\]

\[= \dfrac{x^2}{2x} + \dfrac{6}{2x}\]

On additionne les numérateurs :

\[\dfrac{x^2 + 6}{2x}\]

Synthèse : Développer vs Factoriser

Développer

  • Produit → Somme
  • Distributivité
  • Double distributivité
  • Identités remarquables

But : Forme réduite et ordonnée

Factoriser

  • Somme → Produit
  • Facteur commun
  • Identités remarquables
  • Stratégie par étapes

But : Simplifier, résoudre

Ce sont des opérations inverses !

Points clés à retenir

  1. Polynôme : Somme de monômes, à présenter sous forme réduite et ordonnée
  2. Développer : Maîtriser distributivité, double distributivité et les 3 identités remarquables
  3. Factoriser : Stratégie par étapes (facteur commun puis identités)
  4. Identités remarquables : Les connaître dans les deux sens (développement ET factorisation)
  5. Vérification : Toujours vérifier en développant la forme factorisée
